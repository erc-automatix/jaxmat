class SmallStrainState[source]#

Bases: AbstractState

State representation for small-strain behaviors.

This class stores the current strain \(\beps\) and stress \(\bsig\) tensors under the assumption of infinitesimal (small) deformations. It also supports internal state variables such as plastic strain, damage, or other material history quantities through the internal attribute.

class FiniteStrainState[source]#

Bases: AbstractState

State representation for finite-strain continuum mechanics.

This class encapsulates the deformation gradient \(\bF\) (F) and first Piola-Kirchhoff stress \(\bP\) (PK1), along with optional internal variables. It provides convenience properties for converting between common stress measures: second Piola-Kirchhoff \(\bS\) (PK2) and Cauchy \(\bsig\) (sig) stresses.

class Physics[source]#

Bases: object

Declaration of the variables exchanged by a (multiphysics) behavior.

Following the terminology:

  • gradients are the driving inputs whose conjugates are computed by the behavior (strain \(\beps\), deformation gradient \(\bF\), pore pressure \(p\), temperature gradient…);

  • fluxes are the computed outputs, the thermodynamic forces conjugate to the gradients (stress \(\bsig\), fluid content \(\zeta\), heat flux \(\boldsymbol{q}\)…);

  • external variables are known inputs with no conjugate output (temperature \(T\)…).

Internal state variables are not declared here: they keep living in state.internal.

A Physics is immutable and hashable, and is built with make_physics(). The corresponding state class, input and flux containers are generated on first use and cached, so equal declarations always give the same classes (stable pytree structures for jit, scan and serialization).

make_physics(name, *, gradients, fluxes, external=None, aliases=None)[source]#

Declare the variables of a behavior and get the matching state class for free.

Each variable is declared by name with an initializer: a tensor class (SymmetricTensor2), a zero-argument factory (Tensor2.identity), a number (a scalar with that initial value) or Vector. Gradients and fluxes are listed in matching (conjugate) order.

POROELASTICITY = make_physics(
    "Poroelasticity",
    gradients={"strain": SymmetricTensor2, "p": 0.0},
    fluxes={"stress": SymmetricTensor2, "zeta": 0.0},
    aliases={"eps": "strain", "sig": "stress"},
)
state = POROELASTICITY.State()  # fields: internal, strain, p, stress, zeta
